# Старший Брат

Интерактивный навигатор по участникам Telegram-сообщества «Старший брат».

Проект превращает Telegram-визитки участников в локально обрабатываемую интерактивную карту сообщества: поиск людей по компетенциям и задачам, персональные рекомендации, избранное, сферы и похожие вызовы.

## Канонические документы

Перед любыми существенными изменениями нужно сверяться с этими файлами:

1. [`PRODUCT.md`](./PRODUCT.md) — что за продукт мы строим, для кого, какие функции входят в MVP и какие продуктовые правила нельзя нарушать.
2. [`ARCHITECTURE.md`](./ARCHITECTURE.md) — техническая архитектура: React/TypeScript/Vite, Telegram parser, IndexedDB, search, recommendations, PWA, testing и deployment.
3. [`ROADMAP.md`](./ROADMAP.md) — последовательность разработки от каркаса приложения до production release.
4. [`SECURITY.md`](./SECURITY.md) — обязательные privacy/security правила для публичного репозитория и приватных Telegram-данных.

Приоритет при конфликте решений:

```text
PRODUCT.md
  ↓
ARCHITECTURE.md
  ↓
ROADMAP.md
  ↓
конкретная реализация
```

## Статус

Проект находится на стадии подготовки финальной продуктовой версии.

Текущая задача — перейти от экспериментальных standalone HTML-прототипов к нормальной production-кодовой базе с тестируемым parser, IndexedDB, PWA и последовательным QA.

## Архитектурный принцип

MVP — local-first.

```text
Telegram messages.html
        ↓
локальный parser
        ↓
нормализованные профили
        ↓
IndexedDB
        ↓
search / recommendations
        ↓
UI
```

Реальные визитки не должны отправляться на сервер по умолчанию.

## Важно о данных

Репозиторий публичный.

Нельзя коммитить:

- реальные Telegram-экспорты;
- `messages.html`;
- фотографии участников;
- базы профилей;
- локальные IndexedDB dumps;
- реальные персональные fixtures;
- `.env`, токены и credentials.

Для тестов используются только синтетические данные. Полные правила находятся в [`SECURITY.md`](./SECURITY.md).
