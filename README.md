# Старший Брат

Интерактивный навигатор по участникам Telegram-сообщества «Старший брат».

## Источник истины

Главное продуктовое описание проекта находится в [`PRODUCT.md`](./PRODUCT.md).

Все продуктовые, UX- и архитектурные решения должны сверяться с этим документом до реализации.

## Статус

Проект находится на стадии подготовки финальной продуктовой версии.

## Важно о данных

Репозиторий публичный, поэтому реальные Telegram-экспорты, `messages.html`, фотографии участников, локальные базы и другие приватные данные сообщества нельзя коммитить в GitHub.

Парсинг исходного Telegram-экспорта по продуктовой концепции выполняется локально на устройстве пользователя.
